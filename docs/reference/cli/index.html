CLI Reference

Build the launcher once, then call it directly:

Terminal
./gradlew :modules:cli:installDist
export PATH="$PWD/modules/cli/build/install/contextgraph/bin:$PATH"

contextgraph <command> [options]

Working on the ContextGraph sources themselves, ./gradlew :modules:cli:run --args="<command>" runs the same CLI without installing, at the cost of a Gradle startup per command.

Working directory
All commands read .contextgraph/config.json relative to the current working directory, not the project being indexed.
Two database files
.contextgraph/graph.db is the committed baseline, written only by ci-reindex in CI, so a fresh clone is queryable before anything has been indexed locally. Everything else writes .contextgraph/graph.local.db, a gitignored overlay seeded by copying the baseline on first local write. Reads prefer the overlay and fall back to the baseline.

init

Initialize .contextgraph/ in the current directory with a default config.json.

Terminal
contextgraph init

index

Index a directory into the knowledge graph. Skips files unchanged since the last run.

Terminal
contextgraph index [path]

# path defaults to "." (current directory)
contextgraph index /path/to/project

refresh

Re-parse changed files and bring the local graph back in sync with the working tree. Which files changed is decided by checksum comparison, the same mechanism index uses, so a refresh with nothing to do is cheap.

Terminal
contextgraph refresh

watch

Watch the working tree and keep the local graph current as files change. Runs in the foreground until interrupted.

Opt-in. It refuses to start unless watcher.enabled is true in .contextgraph/config.json, and no other command can reach the watcher — it never starts as a side effect of anything else. Bursts of events (a branch switch touching thousands of files) coalesce into a single reindex via the debounce interval, and a periodic full rescan covers watch registrations the OS drops.

Terminal
contextgraph config set watcher.enabled true
contextgraph watch

ci-reindex

Reindex from scratch and write the committed baseline .contextgraph/graph.db. This is the only command that writes it.

It refuses to run when an interactive terminal is attached, which is what keeps the baseline single-writer; set CONTEXTGRAPH_CI=true to override. LiteLLM is forced off regardless of committed config, so this path never needs credentials. Output is one line of JSON on stdout for machine-readable CI logs, with human-readable progress on stderr.

Terminal
contextgraph ci-reindex [path]

search

Full-text search across all graph nodes.

Terminal
contextgraph search <query> [--limit N] [--min-confidence 0.5] [--semantic]

contextgraph search "authentication" --limit 10 --min-confidence 0.7
FlagDefaultDescription
--limit20Maximum number of results
--min-confidence0.5Minimum node confidence score
--semanticoffRank modules by semantic similarity to the query. Embeds the query only; falls back to keyword search with no embedding endpoint or no module vectors — see describe-modules

node

Show a node's details and provenance by ID.

Terminal
contextgraph node <nodeId>

expand

BFS neighborhood expansion from a node — returns all reachable nodes within the given depth.

Terminal
contextgraph expand <nodeId> [--depth 2]

path

Find the shortest path between two nodes.

Terminal
contextgraph path <fromId> <toId>

report

Generate GRAPH_REPORT.md and graph.html in the output directory.

Terminal
contextgraph report [--output .]

describe-modules

Author LLM descriptions for modules that lack one, embed every described module's summary, and flag descriptions made stale by a changed symbol inventory. Requires litellm.enabled=true — with LLM calls off it makes none and leaves modules undescribed.

This is a deliberate, explicit step. It is never part of index.

Terminal
contextgraph describe-modules [--regenerate-stale]
FlagDefaultDescription
--regenerate-staleoffRegenerate descriptions a prior run flagged stale, instead of only flagging them

export

Export the full graph as a JSON snapshot.

Terminal
contextgraph export [graph.json]

serve-mcp

Start the MCP server over stdio. See MCP Server for full documentation.

Terminal
contextgraph serve-mcp

config set

Update a configuration value in .contextgraph/config.json.

Terminal
contextgraph config set <key> <value>
KeyExample value
litellm.enabledtrue
litellm.base-urlhttp://localhost:4000
litellm.modelclaude-opus-4-7
litellm.rate-limit10
max-file-size-mb25
watcher.enabledtrue
watcher.debounce-ms500
watcher.fallback-interval-ms30000

Any other key is rejected with the list of valid ones. Options without a config set key — include and exclude patterns, module roots — are edited directly in .contextgraph/config.json.
