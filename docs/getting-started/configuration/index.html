Configuration

ContextGraph reads its configuration from .contextgraph/config.json in your project directory. Run init to create a default file, or edit it manually.

Full config reference

.contextgraph/config.json
{
  "litellm": {
    "enabled": false,
    "baseUrl": "http://localhost:4000",
    "model": "gpt-4o",
    "rateLimitPerMinute": 10,
    "timeoutSeconds": 30
  },
  "includePatterns": ["**/*"],
  "excludePatterns": [
    "**/.git/**",
    "**/node_modules/**",
    "**/build/**",
    "**/.gradle/**",
    "**/.contextgraph/**",
    "**/target/**",
    "**/__pycache__/**"
  ],
  "ignoreSecrets": true,
  "maxFileSizeBytes": 10485760,
  "moduleRoots": [],
  "watcher": {
    "enabled": false,
    "debounceMillis": 500,
    "fallbackIntervalMillis": 30000
  }
}

Options

KeyDefaultDescription
litellm.enabledfalseEnable LLM-powered semantic extraction
litellm.baseUrlhttp://localhost:4000LiteLLM proxy endpoint
litellm.modelgpt-4oModel name (any LiteLLM-compatible)
litellm.rateLimitPerMinute10Max LLM calls per minute
litellm.timeoutSeconds30Per-call timeout in seconds
includePatterns["**/*"]Glob patterns for files to include
excludePatternsbuild dirs, .git…Glob patterns for files to skip
maxFileSizeBytes10485760 (10 MB)Files larger than this are skipped
ignoreSecretstrueSkip files that look like secrets rather than indexing them
moduleRoots[]Explicitly declared module boundaries, overriding build-file detection for the same path. This is how a boundary no build file expresses gets in — an iOS target declared in an Xcode project, say, since .pbxproj is not parsed. Each entry takes a repo-relative path and an optional name, defaulting to the last path segment
watcher.enabledfalseOpt-in file watcher. watch refuses to start without it, and nothing else can start the watcher
watcher.debounceMillis500A burst of filesystem events collapses into one reindex this long after it starts
watcher.fallbackIntervalMillis30000Full rescan interval independent of events — covers watch registrations the OS drops silently

Setting values via CLI

You can update config values without editing JSON directly:

Terminal
# Enable semantic extraction
contextgraph config set litellm.enabled true

# Point at a different model
contextgraph config set litellm.model claude-opus-4-7

# Change the LiteLLM endpoint
contextgraph config set litellm.base-url http://localhost:4000

# Increase max file size to 25 MB
contextgraph config set max-file-size-mb 25

# Turn the watcher on
contextgraph config set watcher.enabled true

The accepted keys are litellm.base-url, litellm.model, litellm.enabled, litellm.rate-limit, max-file-size-mb, watcher.enabled, watcher.debounce-ms and watcher.fallback-interval-ms. Anything else is rejected. Include and exclude patterns and module roots have no config set key — edit the JSON for those.

Enabling semantic extraction

Semantic extraction sends file contents to an LLM to extract high-level concepts, decisions, and relationships. It also unlocks describe-modules, which authors a description for each module and embeds it — the vectors search --semantic ranks against. Everything else in ContextGraph works with LLM calls off, which is the default. To use it:

  1. Start a LiteLLM proxy in front of your preferred model:
Terminal
pip install litellm
litellm --model claude-opus-4-7
  1. Enable it in your config:
Terminal
contextgraph config set litellm.enabled true
contextgraph config set litellm.model claude-opus-4-7

# Then author and embed module descriptions
contextgraph describe-modules
Note
Semantic extraction is rate-limited to rateLimitPerMinute calls. Set this low enough that you don't exceed your LLM provider's limits. The default of 10 calls/minute is conservative.

Filtering files

Use glob patterns to control which files get indexed. Patterns are matched against the full file path.

.contextgraph/config.json — Kotlin-only example
{
  "includePatterns": ["**/*.kt", "**/*.md", "**/*.sql"],
  "excludePatterns": ["**/build/**", "**/.gradle/**"]
}
